# ⚖️ BMI Calculator

A simple and user-friendly BMI calculator that helps users quickly determine their Body Mass Index using height and weight inputs.

---

## 📌 Features

- Easy input for height and weight  
- Instant BMI calculation  
- Displays BMI category (Underweight, Normal, Overweight, Obese)  
- Clean and responsive interface
